# 実装計画・仕様書: アプリメニューのドラッグ移動ハンドル配置・座標永続化機能

## 1. 概要・目的
片手操作時の手の大きさや持ち手（左手/右手）に応じて、アプリメニュー（5×6グリッド画面）の位置を直感的に微調整できるよう、検索バーの横に **ドラッグ移動ハンドル（`⋮⋮` / Grip Handle）** を配置する。
ハンドルをドラッグすることでメニュー全体がスムーズに追従し、指を離した際に新しい位置座標を自動保存する。

---

## 2. 変更対象と実装内容

### ① `layout_app_menu.xml` へのドラッグハンドル追加
- 検索バーの横にドラッグハンドルボタン（`iv_drag_handle`）を追加。
- アイコンにはベクターDrawable (`ic_drag_handle.xml`) を作成・使用。

### ② `SavedData.kt` へのメニュー座標管理メソッド追加
- `getAppMenuX()`, `getAppMenuY()`
- `setAppMenuPosition(x, y)`
- デフォルト値は未設定（-1, -1 = 画面中央表示）

### ③ `AppMenu.kt` でのドラッグ処理・座標復元
- 初期レイアウト作成時に `SavedData` の座標（設定済みなら `Gravity.TOP or Gravity.START` + (x, y)）を適用。
- ドラッグハンドルの `OnTouchListener` で `ACTION_DOWN`, `ACTION_MOVE`, `ACTION_UP` を処理。
- 画面外はみ出し防止のクランプ計算。
- 移動完了（`ACTION_UP`）時に座標を `SavedData` に非同期保存し、触覚フィードバックを発動。

---

## 3. 保証事項
- アプリ検索・絞り込み入力、クリアボタンの動作は100%維持
- テンキー入力時（01〜30）の数値ラベルプレビューと起動は100%維持
- 画面回転時も画面外へ脱落しない安全設計
